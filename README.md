# Indian_Tourist_Analysis
Excel-based India Tourism Data Analysis project using Pivot Tables, KPIs, charts, and advanced formulas.

 📌 Project Overview

This project focuses on analyzing Indian tourism data using Microsoft Excel to identify tourism trends, visitor behavior, accommodation patterns, booking insights, and customer feedback.

The project uses multiple datasets including places, hotels, visitors, bookings, and reviews to generate meaningful business insights through data analysis and visualization.

🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Advanced Excel Formulas
- KPI Analysis
- Data Cleaning
- Data Visualization
- Dashboard

📂 Dataset Structure

The workbook contains the following sheets:

- **Places** – Tourist places, states, regions, categories, ratings, and annual visitors.
- **Hotels** – Hotel information, hotel types, prices, and ratings.
- **Visitors** – Visitor demographics, countries, visit months, and travel groups.
- **Bookings** – Booking details, transport, stay duration, total cost, and payment modes.
- **Reviews** – Customer ratings and feedback.
- **Pivotable** – Pivot Table based analysis.
- **KPI** – Key Performance Indicators.
- **Dashboard** – Interactive tourism analysis dashboard.
